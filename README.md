# Carter Nguyen — Portfolio

Personal portfolio for Carter Nguyen. Built with Next.js App Router, TypeScript, Tailwind CSS, Motion, and React Three Fiber.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Content

Edit structured data in `src/data/`:

- `site.ts` — name, links, hero copy
- `projects.ts` — featured projects + case studies
- `experience.ts` — roles and education
- `interests.ts` — personal interest stories

Replace placeholder photos and add `public/resume.pdf` when ready.
